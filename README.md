Sistema de gestión de mascotas con arquitectura desacoplada correspondiente a la Semana 8.
- `vetconnect-react`: Cliente frontend SPA construido en React con Vite (Puerto 5173).
- `vetconnect-api`: Backend API REST modular construido en NestJS (Puerto 3000).
```bash
cd vetconnect-api
npm install
npm run start:dev
cd vetconnect-react
npm install
npm run dev
